# Álgebra elemental
**Guía simple · Álgebra escolar y fundamentos · 10°–11°**
*Expresiones, factorización, ecuaciones e inecuaciones.*

## 1. Expresiones algebraicas y términos semejantes
Una **expresión algebraica** combina números, variables y operaciones. En $5x^2 - 3x + 7$ el término $5x^2$ tiene coeficiente $5$ y exponente $2$, el término constante es $7$ y el grado de la expresión es $2$.

Dos términos son **semejantes** si tienen la misma parte literal (mismas variables con los mismos exponentes). La regla de oro: solo se pueden sumar o restar términos semejantes. La **propiedad distributiva** conecta productos con sumas:
$$a(b + c) = ab + ac$$

**Mini-ejemplo.** Simplifica $6x + 3 - 2x + 4$. Agrupando semejantes: $(6x - 2x) + (3 + 4) = 4x + 7$.

## 2. Leyes de exponentes
Un exponente indica multiplicación repetida; las leyes se deducen contando factores.
$$a^m \cdot a^n = a^{m+n}$$
$$\frac{a^m}{a^n} = a^{m-n} \quad (a \neq 0)$$
$$(a^m)^n = a^{m \cdot n}$$
$$(ab)^n = a^n b^n, \qquad \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n} \quad (b \neq 0)$$
$$a^0 = 1 \quad (a \neq 0), \qquad a^{-n} = \frac{1}{a^n} \quad (a \neq 0), \qquad a^{m/n} = \sqrt[n]{a^m}$$

**Mini-ejemplo.** $\dfrac{12x^5 y^{-3}}{4x^2 y^2} = 3x^{5-2} y^{-3-2} = \dfrac{3x^3}{y^5}$.

## 3. Productos notables
Son multiplicaciones frecuentes cuyo resultado conviene recordar; se deducen aplicando la distributiva.
$$(a + b)^2 = a^2 + 2ab + b^2, \qquad (a - b)^2 = a^2 - 2ab + b^2$$
$$(a + b)(a - b) = a^2 - b^2$$
$$(a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3$$
$$a^3 + b^3 = (a + b)(a^2 - ab + b^2), \qquad a^3 - b^3 = (a - b)(a^2 + ab + b^2)$$

**Mini-ejemplo.** $(x + 4)^2 = x^2 + 2 \cdot 4 \cdot x + 4^2 = x^2 + 8x + 16$.

## 4. Factorización
Factorizar es escribir una expresión como producto de factores más simples; es la operación inversa de expandir.

1. **Factor común.** $6x^3 + 9x^2 = 3x^2(2x + 3)$.
2. **Diferencia de cuadrados.** $x^2 - 16 = (x + 4)(x - 4)$.
3. **Trinomio cuadrado perfecto.** $x^2 + 6x + 9 = (x + 3)^2$.
4. **Trinomio $x^2 + bx + c$.** Busca dos números que sumen $b$ y multipliquen $c$.
5. **Agrupación.** $ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)$.

**Mini-ejemplo.** Factoriza $2x^3 - 8x = 2x(x^2 - 4) = 2x(x + 2)(x - 2)$.

## 5. Ecuaciones lineales
Una ecuación es una igualdad entre dos expresiones; resolverla es hallar el valor que la hace verdadera. Cualquier operación aplicada a un lado debe aplicarse también al otro.

Método: elimina paréntesis, elimina denominadores, agrupa la incógnita en un lado y las constantes en el otro, reduce términos semejantes y despeja.

**Mini-ejemplo.** Resuelve $3(x - 2) + 5 = 2x + 7$.
$$3x - 6 + 5 = 2x + 7 \Rightarrow 3x - 1 = 2x + 7 \Rightarrow x = 8$$

## 6. Ecuaciones cuadráticas
Tienen la forma $ax^2 + bx + c = 0$ con $a \neq 0$. La **fórmula general** es:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
El **discriminante** $\Delta = b^2 - 4ac$ decide el tipo de soluciones: $\Delta > 0$ da dos soluciones reales distintas, $\Delta = 0$ una solución doble y $\Delta < 0$ dos soluciones complejas conjugadas. Cuando el trinomio se factoriza fácil, las soluciones se leen directo.

**Mini-ejemplo.** Resuelve $x^2 - 5x + 6 = 0$: $(x - 2)(x - 3) = 0$, luego $x = 2$ o $x = 3$.

## 7. Inecuaciones
Se resuelven como las ecuaciones, con una diferencia crítica: **al multiplicar o dividir por un número negativo, el sentido de la desigualdad se invierte**.

**Mini-ejemplo.** $-2x + 1 > 7 \Rightarrow -2x > 6 \Rightarrow x < -3$ (se invirtió).

## 8. Valor absoluto
$|x|$ es la distancia de $x$ al cero. Las inecuaciones con valor absoluto se desdoblan:
$$|x| = \begin{cases} x & \text{si } x \geq 0 \\ -x & \text{si } x < 0 \end{cases}$$
$$|x| < r \Leftrightarrow -r < x < r, \qquad |x| > r \Leftrightarrow x > r \ \text{o} \ x < -r$$

**Mini-ejemplo.** $|2x - 6| \leq 4 \Rightarrow -4 \leq 2x - 6 \leq 4 \Rightarrow 1 \leq x \leq 5$.

5. Simplifica $(3x^2)^2$.

### Nivel 2 — Productos notables y factorización

7. Expande $(x - 7)(x + 7)$.
8. Factoriza $x^2 - 16$.
9. Factoriza $x^2 + 6x + 8$.
10. Factoriza $5x^2 - 20$.

### Nivel 3 — Ecuaciones lineales y cuadráticas

12. Resuelve $3(x - 1) = 2x + 5$.
13. Resuelve $x^2 - 5x = 0$.
14. Resuelve $x^2 - 6x + 8 = 0$.
15. Resuelve con la fórmula general $x^2 - 2x - 2 = 0$.

### Nivel 4 — Inecuaciones, valor absoluto y aplicaciones
16. Resuelve $3x + 2 > 11$.
17. Resuelve $-2x \geq 8$.
18. Resuelve $|x - 4| < 3$.
19. Resuelve $|x + 1| \geq 5$.
20. La suma de dos números consecutivos es $45$. Halla el mayor.
