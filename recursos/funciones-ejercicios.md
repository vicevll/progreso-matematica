# Funciones · 50 ejercicios

**Área:** Funciones y trigonometría · **Nivel:** 10°–11° · Dominio, rango, composición, inversa y tipos básicos.

## Formulario

### Función y notación

Una función asigna a cada entrada una única salida. Se escribe $f: A \to B$ con $y = f(x)$, donde $A$ es el dominio y $B$ el codominio.

### Dominio

- $\dfrac{1}{g(x)}$ exige $g(x) \neq 0$.
- $\sqrt{g(x)}$ (raíz par) exige $g(x) \geq 0$.
- $\ln(g(x))$ exige $g(x) > 0$.

### Composición

$$(f \circ g)(x) = f\big(g(x)\big), \qquad (g \circ f)(x) = g\big(f(x)\big)$$

### Inversa

$f^{-1}$ existe si $f$ es inyectiva y cumple $f\big(f^{-1}(x)\big) = x$. Se obtiene despejando $y$ tras intercambiar $x$ y $y$.

### Tipos de funciones

- Constante: $f(x) = c$.
- Lineal: $f(x) = mx + b$.
- Cuadrática: $f(x) = ax^2 + bx + c$.
- Cúbica: $f(x) = x^3$.
- Valor absoluto: $f(x) = |x|$.
- Racional: $f(x) = \dfrac{1}{x}$.

### Clasificación de funciones

- Inyectiva: $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$.
- Sobreyectiva: todo el codominio es alcanzado.
- Biyectiva: inyectiva y sobreyectiva; tiene inversa.

## Ejercicios (50)

### Nivel 1 · Dominio y rango

1. Halla el dominio de $f(x) = \dfrac{1}{x - 3}$.
2. Halla el dominio de $f(x) = \sqrt{x - 5}$.
3. Halla el dominio de $f(x) = \sqrt{2 - x}$.
4. Halla el dominio de $f(x) = \dfrac{1}{\sqrt{x - 1}}$.
5. Halla el dominio de $f(x) = \ln(x + 4)$.
6. Halla el rango de $f(x) = x^2 + 2$.
7. Halla el rango de $f(x) = \sqrt{x - 1}$.
8. Halla el rango de $f(x) = -x^2$.
9. Halla el dominio de $f(x) = \dfrac{x}{x^2 - 9}$.
10. Halla el rango de $f(x) = \dfrac{1}{x}$.

### Nivel 2 · Evaluación, gráficas y tipos

11. Si $f(x) = 2x - 1$, calcula $f(3)$ y $f(-2)$.
12. Si $f(x) = x^2 + 1$, calcula $f(0)$, $f(2)$ y $f(-2)$.
13. Halla la pendiente y el corte con el eje $y$ de $f(x) = 3x - 2$.
14. Halla el vértice de $f(x) = x^2 - 2x + 1$.
15. Halla las raíces de $f(x) = x^2 - 9$.
16. Clasifica $f(x) = 2x + 1$ y da su pendiente.
17. Halla $f(0)$ para $f(x) = x^2 + 5x$.
18. Clasifica $f(x) = 3x + 2$ (constante, lineal, cuadrática, ...).
19. Clasifica $f(x) = x^2 - 4x + 1$.
20. Clasifica $f(x) = 2$.

### Nivel 3 · Composición

21. Con $f(x) = x + 1$ y $g(x) = 3x$, halla $(f \circ g)(x)$.
22. Con $f(x) = x + 1$ y $g(x) = 3x$, halla $(g \circ f)(x)$.
23. Con $f(x) = x^2$ y $g(x) = x - 2$, halla $(f \circ g)(x)$.
24. Con $f(x) = x^2$ y $g(x) = x - 2$, halla $(g \circ f)(x)$.
25. Con $f(x) = \sqrt{x}$ y $g(x) = x - 3$, halla el dominio de $f \circ g$.
26. Con $f(x) = 2x - 1$ y $g(x) = x^2$, calcula $(f \circ g)(2)$.
27. Con $f(x) = 2x - 1$ y $g(x) = x^2$, calcula $(g \circ f)(2)$.
28. Con $f(x) = x + 2$ y $g(x) = \dfrac{1}{x}$, halla $(f \circ g)(x)$.
29. Con $f(x) = 3x$ y $g(x) = x + 4$, halla $(g \circ f)(x)$.
30. Con $f(x) = x^2 - 1$ y $g(x) = x + 1$, halla $(f \circ g)(x)$.

### Nivel 4 · Inversa

31. Halla la inversa de $f(x) = x + 5$.
32. Halla la inversa de $f(x) = 3x$.
33. Halla la inversa de $f(x) = 2x - 4$.
34. Halla la inversa de $f(x) = \dfrac{x - 1}{2}$.
35. Halla la inversa de $f(x) = \dfrac{1}{x}$.
36. Halla la inversa de $f(x) = \dfrac{x + 1}{x - 2}$.
37. Halla la inversa de $f(x) = x^3$.
38. Halla la inversa de $f(x) = \sqrt{x}$ con $x \geq 0$.
39. Halla la inversa de $f(x) = 5x + 2$.
40. Halla la inversa de $f(x) = \dfrac{2x}{x + 1}$.

### Nivel 5 · Cuadráticas y clasificación

41. Halla el vértice de $f(x) = x^2 + 3$.
42. Halla el vértice de $f(x) = (x - 2)^2$.
43. Halla las raíces de $f(x) = x^2 - 4$.
44. Halla el vértice de $g(x) = (x - 2)^2 + 3$.
45. Halla el dominio de $g(x) = 2\sqrt{x}$.
46. Halla el dominio de $g(x) = \sqrt{x + 1}$.
47. Halla el rango de $g(x) = -\sqrt{x}$.
48. ¿Es inyectiva $f(x) = x^2$ restringida a $[0, \infty)$?
49. ¿Es sobreyectiva $f(x) = x^2$ con $f: \mathbb{R} \to \mathbb{R}$?
50. ¿Es biyectiva $f(x) = x^3$ con $f: \mathbb{R} \to \mathbb{R}$?
