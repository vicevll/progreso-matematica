# Geometría euclidiana · 50 ejercicios

**Área:** Funciones, trigonometría y geometría · **Nivel:** 10°–11° · Axiomas, congruencia, semejanza, círculos y demostraciones.

## Formulario

**Ángulos y paralelas**

$$\text{Complementarios: } \alpha + \beta = 90°, \qquad \text{Suplementarios: } \alpha + \beta = 180°$$

$$S = (n - 2)\cdot 180°, \qquad \text{suma de exteriores} = 360°, \qquad \text{interno regular} = \frac{(n-2)180°}{n}$$

**Triángulos**

$$A + B + C = 180°, \qquad \text{exterior} = \text{suma de los no adyacentes}$$

$$|b - c| < a < b + c \qquad \text{(desigualdad triangular)}$$

**Semejanza y Tales**

$$\frac{AD}{DB} = \frac{AE}{EC}, \qquad \text{perímetros en razón } k, \qquad \text{áreas en razón } k^2$$

**Pitágoras**

$$a^2 + b^2 = c^2, \qquad d = \sqrt{(\Delta x)^2 + (\Delta y)^2}$$

**Círculo**

$$\text{inscrito} = \frac{\text{central}}{2}, \qquad \text{inscrito en semicírculo} = 90°, \qquad \text{opuestos inscritos suman } 180°$$

$$A = \pi r^2, \qquad C = 2\pi r, \qquad A_{\text{sector}} = \frac{\theta}{2}r^2$$

**Áreas y volúmenes**

$$A_{\triangle} = \frac{bh}{2}, \qquad A = \sqrt{s(s-a)(s-b)(s-c)}, \qquad A_{\text{trapecio}} = \frac{(B+b)h}{2}, \qquad A_{\text{rombo}} = \frac{d_1 d_2}{2}$$

$$V_{\text{prisma}} = A_b h, \qquad V_{\text{cilindro}} = \pi r^2 h, \qquad V_{\text{cono}} = \frac{\pi r^2 h}{3}, \qquad V_{\text{esfera}} = \frac{4}{3}\pi r^3$$

## Ejercicios (50)

1. Halla el complemento de $28°$.
2. Halla el suplemento de $113°$.
3. Dos ángulos opuestos por el vértice: uno mide $47°$. Halla el opuesto.
4. Dos rectas paralelas cortadas por una transversal: un ángulo mide $72°$. Halla su alterno interno.
5. En el mismo caso anterior, halla el colateral interno de $72°$.
6. Halla la suma de los ángulos internos de un octágono.
7. Halla cada ángulo interno de un hexágono regular.
8. Halla el ángulo exterior de un polígono regular de 12 lados.
9. Dos ángulos de un triángulo miden $38°$ y $79°$. Halla el tercero.
10. En un triángulo isósceles el ángulo del vértice mide $100°$. Halla cada ángulo de la base.
11. Un ángulo exterior mide $140°$ y uno de los internos no adyacentes mide $60°$. Halla el otro.
12. ¿Existe un triángulo de lados $5$, $7$ y $13$? Justifica.
13. Halla el perímetro de un triángulo equilátero de lado $8$.
14. Clasifica el triángulo de lados $8$, $15$ y $17$.
15. Halla el área de un triángulo de base $12$ y altura $7$.
16. ¿Qué criterio de congruencia usa dos lados y el ángulo comprendido?
17. ¿Qué criterio de congruencia usa los tres lados?
18. ¿Qué criterio de congruencia usa dos ángulos y el lado comprendido?
19. ¿Es válido LLA como criterio general de congruencia?
20. Dos triángulos congruentes tienen lados $7$, $9$ y $11$. Halla el perímetro del otro.
21. Dos triángulos semejantes tienen razón $k = 2$ (mayor respecto al menor). El lado menor mide $9$. Halla el correspondiente en el mayor.
22. El área del triángulo menor es $15$ y $k = 2$. Halla el área del mayor.
23. Dos triángulos semejantes tienen lados $6$ y $8$; sus correspondientes miden $9$ e $y$. Halla $y$.
24. Una persona de $1.8$ m proyecta una sombra de $2.4$ m; un poste proyecta $8$ m a la misma hora. Halla la altura del poste.
25. En el teorema de Tales, $AD = 4$, $DB = 6$ y $AE = 6$. Halla $EC$.
26. Los catetos de un triángulo rectángulo miden $6$ y $8$. Halla la hipotenusa.
27. Un cateto mide $9$ y la hipotenusa $41$. Halla el otro cateto.
28. Halla la diagonal de un cuadrado de lado $5$.
29. Halla la diagonal de un rectángulo de lados $6$ y $8$.
30. En una terna pitagórica se conocen $5$ y $12$. Halla la hipotenusa.
31. Halla la circunferencia de un círculo de radio $7$.
32. Halla el área de un círculo de radio $7$.
33. Halla el área de un círculo de diámetro $20$.
34. Un ángulo central mide $120°$. Halla el ángulo inscrito que subtiende el mismo arco.
35. ¿Cuánto mide un ángulo inscrito en un semicírculo?
36. Un cuadrilátero inscrito tiene un ángulo de $95°$. Halla su ángulo opuesto.
37. Un ángulo central mide $46°$. Halla el inscrito que subtiende el mismo arco.
38. Halla el área de un trapecio de bases $12$ y $8$ y altura $5$.
39. Halla el área de un paralelogramo de base $11$ y altura $6$.
40. Halla el área del triángulo de lados $13$, $14$ y $15$ (Herón).
41. Halla el área de un triángulo equilátero de lado $6$.
42. Halla el área de un sector circular de radio $6$ y ángulo $\pi/3$.
43. Halla el área de un rombo de diagonales $10$ y $16$.
44. Halla el área de un círculo de radio $3$.
45. Halla el área de la corona circular entre radios $5$ y $3$.
46. Halla el volumen de un cubo de arista $4$.
47. Halla el volumen de un cilindro de radio $3$ y altura $5$.
48. Halla el volumen de un prisma de área basal $12$ y altura $7$.
49. Halla el volumen de una pirámide de área basal $20$ y altura $9$.
50. Halla el volumen de una esfera de radio $3$.
