# Álgebra elemental · 50 ejercicios
**Cuaderno de práctica · Álgebra escolar y fundamentos · 10°–11°**
*Expresiones, factorización, ecuaciones e inecuaciones.*

## Formulario
### Exponentes y radicales
- $a^m \cdot a^n = a^{m+n}$
- $\dfrac{a^m}{a^n} = a^{m-n}$ con $a \neq 0$
- $(a^m)^n = a^{m \cdot n}$
- $(ab)^n = a^n b^n$
- $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ con $b \neq 0$
- $a^0 = 1$ con $a \neq 0$
- $a^{-n} = \dfrac{1}{a^n}$ con $a \neq 0$
- $a^{m/n} = \sqrt[n]{a^m}$
- $(a \cdot b)^m = a^m \cdot b^m$

### Productos notables
- $(a + b)^2 = a^2 + 2ab + b^2$
- $(a - b)^2 = a^2 - 2ab + b^2$
- $(a + b)(a - b) = a^2 - b^2$
- $(a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3$
- $(a - b)^3 = a^3 - 3a^2 b + 3ab^2 - b^3$
- $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
- $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$

### Factorización
- **Factor común.** $ab + ac = a(b + c)$
- **Diferencia de cuadrados.** $a^2 - b^2 = (a + b)(a - b)$
- **Trinomio cuadrado perfecto.** $a^2 \pm 2ab + b^2 = (a \pm b)^2$
- **Trinomio $x^2 + bx + c$.** Dos números $p, q$ tales que $p + q = b$ y $pq = c$
- **Suma y diferencia de cubos.** Las fórmulas del bloque anterior
- **Agrupación.** $ax + ay + bx + by = (a + b)(x + y)$

### Ecuaciones lineales
- Forma general: $ax + b = 0$ con $a \neq 0$
- Solución: $x = -\dfrac{b}{a}$
- Pasos: distribuir, quitar denominadores, agrupar la incógnita, reducir, despejar y verificar.

### Ecuaciones cuadráticas
- Forma general: $ax^2 + bx + c = 0$ con $a \neq 0$
- Fórmula general: $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
- Discriminante: $\Delta = b^2 - 4ac$
- $\Delta > 0$: dos soluciones reales; $\Delta = 0$: una solución doble; $\Delta < 0$: dos soluciones complejas conjugadas.
- Producto nulo: $A B = 0$ si y solo si $A = 0$ o $B = 0$
- Relaciones de Vieta: $x_1 + x_2 = -\dfrac{b}{a}$ y $x_1 x_2 = \dfrac{c}{a}$
- Completar el cuadrado: $x^2 + bx = \left(x + \dfrac{b}{2}\right)^2 - \dfrac{b^2}{4}$

### Inecuaciones
- Si $a < b$ entonces $a + c < b + c$
- Si $a < b$ y $c > 0$ entonces $ac < bc$
- Si $a < b$ y $c < 0$ entonces $ac > bc$ (el sentido se invierte)
- Notación de intervalos: $[a, b]$, $(a, b)$, $[a, b)$, $(a, b]$, $[a, \infty)$, $(-\infty, b)$

### Valor absoluto
- $|x| = x$ si $x \geq 0$; $|x| = -x$ si $x < 0$
- $|a b| = |a| \, |b|$
- $|a + b| \leq |a| + |b|$ (desigualdad triangular)
- $|x| < r \Leftrightarrow -r < x < r$
- $|x| \leq r \Leftrightarrow -r \leq x \leq r$
- $|x| > r \Leftrightarrow x > r$ o $x < -r$
- $|x| \geq r \Leftrightarrow x \geq r$ o $x \leq -r$

### Traducción de problemas verbales
- Enteros consecutivos: $n$, $n + 1$, $n + 2$
- Perímetro del rectángulo: $P = 2(l + a)$
- Área del rectángulo: $A = l \cdot a$
- Interés simple: $I = C \cdot r \cdot t$
- Movimiento uniforme: $d = v \cdot t$

## Ejercicios (50)
### Nivel 1 — Exponentes y radicales
1. Simplifica $x^5 \cdot x^3$.
2. Simplifica $\dfrac{a^7}{a^2}$.
3. Expande $(2x^3)^2$.
4. Calcula $3^{-2}$.
5. Simplifica $\left(\dfrac{x}{2}\right)^3$.
6. Simplifica $\dfrac{12x^4 y^3}{4x^2 y}$.
7. Calcula $8^{2/3}$.
8. Simplifica $\dfrac{6 m^{-1} n^3}{3 m^{-2} n}$.

### Nivel 2 — Términos semejantes y distributiva
9. Simplifica $5x - 3 + 2x + 8$.
10. Simplifica $4(2x - 3) - 3(x - 1)$.
11. Simplifica $3x(x - 4) + 2x^2$.
12. Simplifica $2(a + 3b) - (a - b)$.
13. Simplifica $\dfrac{x^2 + x}{x}$ con $x \neq 0$.
14. Expande $(x + 1)(x^2 - x + 1)$.

### Nivel 3 — Productos notables
15. Expande $(x + 7)^2$.
16. Expande $(x - 3)^2$.
17. Expande $(2x + 5)^2$.
18. Expande $(x + 9)(x - 9)$.
19. Expande $(3x + 2)(3x - 2)$.
20. Expande $(x + 2)^3$.
21. Expande $(x - 1)^3$.
22. Expande $(x + 2y)(x - 2y)$.

### Nivel 4 — Factorización
23. Factoriza $x^2 - 36$.
24. Factoriza $x^2 + 8x + 15$.
25. Factoriza $x^2 - 5x + 6$.
26. Factoriza $x^2 + 2x - 15$.
27. Factoriza $4x^2 - 9$.
28. Factoriza $3x^3 - 12x$ por completo.
29. Factoriza $x^2 + 10x + 25$.
30. Factoriza $x^3 + 27$.
31. Factoriza $2x^2 + 7x + 3$.

### Nivel 5 — Ecuaciones lineales
32. Resuelve $3x + 5 = 20$.
33. Resuelve $2(x - 3) = x + 4$.
34. Resuelve $5x - 7 = 3x + 9$.
35. Resuelve $\dfrac{x}{2} + 3 = 7$.
36. Resuelve $4 - 2x = 10$.
37. Resuelve $3(x + 2) - 4 = 2(x - 1) + 9$.
38. Resuelve $\dfrac{2x - 1}{3} = 5$.

### Nivel 6 — Ecuaciones cuadráticas
39. Resuelve $x^2 - 9 = 0$.
40. Resuelve $x^2 - 7x + 10 = 0$ por factorización.
41. Resuelve $x^2 + 2x - 8 = 0$ por factorización.
42. Resuelve $2x^2 - 5x + 2 = 0$ por factorización.
43. Resuelve con la fórmula general $x^2 - 4x + 1 = 0$.
44. Resuelve con la fórmula general $x^2 + x + 1 = 0$.

### Nivel 7 — Inecuaciones y valor absoluto
45. Resuelve $2x - 5 > 3$.
46. Resuelve $-3x \leq 12$.
47. Resuelve $|x - 2| < 5$.
48. Resuelve $|2x + 1| \geq 7$.

### Nivel 8 — Problemas verbales
49. La suma de tres enteros consecutivos es $63$. Halla el menor de ellos.
50. El perímetro de un rectángulo es $40$ cm y el largo mide $4$ cm más que el ancho. Halla su área.
