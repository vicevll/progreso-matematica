## Formulario

### Lineales
$$ax + b = c \;\Rightarrow\; x = \frac{c - b}{a}$$

### Cuadráticas
$$ax^{2} + bx + c = 0 \;\Rightarrow\; x = \frac{-b \pm \sqrt{b^{2} - 4ac}}{2a}$$

### Valor absoluto
$$|x| = a \;\Rightarrow\; x = a \text{ o } x = -a$$

### Radicales
$$\sqrt{x} = a \;\Rightarrow\; x = a^{2}$$
